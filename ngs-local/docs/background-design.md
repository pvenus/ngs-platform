# 비나리 배경 설계
배경 설계 → + 버튼은 원본 PNG 1장을 정식 요청한다. 제목과 시간대·계절·분위기·주조색·장소·필수 요청 사항이 필수이며, 추가 요청 사항은 선택이다.
기존 프랍 및 시네마틱과 동일한 UI 컴포넌트를 사용하되, 배경 목록 및 원본은 별도로 관리한다.

`background.source.generate` → `background_source_generate` (기존 이미지 워커 1회) → PDS를 통해 Filex 원본 게시 → 로컬/Space 사본 조회.
기존 시네마틱 원본 및 프랍 작업에는 영향을 주지 않는다. 이 흐름은 별도 애니메이션이나 배경 제거를 생성하지 않는다.
두 마스터 컨셉은 작업을 인수한 워커가 현재 Filex 원본에서 읽는다. 공용 디자인은 시각 스타일과 표현 금지 규칙, 배경 디자인 설계는 공간 구성과 카메라, 동선에 적용한다.


## 배경 원본 + 픽셀 제작

로컬 배경 설계의 **+**은 큐에 `background.pixel.workflow` 1건만 넣는다. Planner의 시네마틱풍 순수 배경 원본 → 원본 PNG를 실제 이미지 레퍼런스로 붙인 픽셀 생성 → 기존 CPU 팔레트 보정 순으로 진행한다. 마지막 단계는 1536×1024 전체에서 좌표를 보존하며 거쳐간 픽셀의 색만 조정한다. 크기 축소, 재확대, 크롭, 배경 제거는 하지 않는다. 공용 표현/캐릭터·프랍 워커는 그대로이다. 세 버전은 별도 PNG로 게시하며 같은 요청의 버전끼리 배경 상세에서 열 수 있다. 로컬 화면에서는 기존 원본 단독 생성 버튼을 표시하지 않으나 과거 요청과 산출물은 그대로 보존한다. Space는 이번 변경의 배포 범위에 포함되지 않는다.
