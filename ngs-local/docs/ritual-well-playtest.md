# 굿상에 물 올리기: 독립 플레이테스트

로컬 NGS의 **비나리 → 퍼즐 설계 → 굿상에 물 올리기 · 테스트**에서 실행한다. 기존 맵, 프랍, 조립 및 퍼즐 데이터를 변경하지 않는다. 테스트 미술과 좌표는 데모 파일에 있고 별도 요청이나 저장이 필요하지 않다.

- **공용 런타임** (`puzzle-state-runtime.mjs`): 이벤트에 연결된 규칙을 고르고 조건과 효과를 검증한다. 유효한 변경을 한꺼번에 반영하며 실패하면 상태를 바꾸지 않는다. 프랍의 상태와 위치를 따로 저장한다. 연타 게이지는 입력 횟수와 경과 시간으로 값을 계산하는 순수 함수다.
- **설계 데이터**: 픽업, 게이지 성공, 드롭 이벤트와 필요 상태, 효과, 연결 포인트를 정의한다. 이름과 상태의 물리 위치 또는 프랍 이미지는 포함하지 않는다.
- **테스트 조립**: 선언한 포인트에 고유 인스턴스를 연결하고 무대에 배치한다. 제상과 우물의 상대 배치만 테스트이며 실제 5구역 굿터 맵에는 반영하지 않는다.
- **웹 표현**: 실제 게임에서는 상호작용 대상을 액터가 결정한다. 이 테스트에서는 프랍 클릭으로 액터의 선택을 대신한다. 우물을 선택하고 F를 누르면 우물 옆에 게이지가 뜬다(팝업 없음). 이동이나 거리 판정은 구현하지 않는다. 스페이스 연타, 취소, 상태별 이미지와 피드백은 웹 UI가 표현한다. 유니티는 이 게이지의 시각 표현에 의존하지 않는다. 이 릴리스에 유니티 어댑터나 본 제작용 조립 편집기는 포함하지 않는다.
- **완료**: 빈 그릇을 획득, 열린 우물에 드롭, 물그릇을 제상에 드롭. 순서를 엉뚱하게 시도해도 자산이 소모되지 않는다. 같은 상태로 시작하려면 처음부터 버튼을 사용한다.
